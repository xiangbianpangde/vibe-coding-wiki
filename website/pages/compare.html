YOLO Mode vs. Responsible Vibe Coding

⚠ 不推荐

YOLO Mode

关闭所有审批，让 agent 编辑文件、跑命令、安装东西都不停下来问。

  • 设任务 → 吃饭 → 回来 → 完成
  • 无人工审批
  • 风险极高
事件：Replit agent 删生产数据库、Lovable PII 泄漏
→
改善
✓ 推荐

Responsible Vibe Coding

持续审查、不放任 YOLO 的 vibe coding 风格。

  • 每次 prompt 都有 checkpoint
  • 自动 + 手动 guardrails
  • 风险可控
工具：Claude Code Auto Mode（分类器免疫 prompt injection）

关键决定点（决定你是哪一种）

是否审查代码？
✗ 否 → Vibe Coding
✓ 是 → Agentic Programming / Engineering
是否每次审批？
✗ 否 → YOLO Mode
✓ 是 → Responsible Vibe Coding
Spec 是否共享契约？
✗ 否 → Ad-hoc Vibe
✓ 是 → SDD / Spec Kit
工具集成层级？
IDE → Cursor / Windsurf
CLI → Claude Code / Codex CLI
