核心定义

"There's a new kind of coding I call 'vibe coding', where you fully give in to the vibes, embrace exponentials, and forget that the code even exists." — Andrej Karpathy, 2025-02-02

⚠️ 重要边界

Vibe Coding ≠ Agentic Programming

Fowler：前者"忘了代码存在"，后者"用 LLM 写代码但仍审查"。Willison：vibe coding 与 agentic engineering 是对立面。

范式

Vibe Coding

Karpathy 2025-02 创造：用自然语言描述意图，由 LLM 自动生成源码，"忘了代码存在"的开发风格。
范式

Agentic Engineering

Karpathy 2026-02 提出取代 vibe coding 的术语。"vibe coding is passé"。
范式

Vibe Engineering

Willison 2025-10 创造：vibe coding 的对立面，专业人士问责式 AI 开发。
方法

SDD

以 spec.md 作为人、AI、测试、审查者之间共享契约的开发方法。GitHub Spec Kit 是工具链。
方法

Context Engineering

管理进入 LLM 上下文窗口的所有信息的工程学科。比 Prompt Engineering 范围更广。
技术

MCP

Model Context Protocol：连接 AI Agent 与外部工具/数据源的开放标准，AI 时代的 USB。
质量

Guardrails

自动化检查，专门捕捉 AI 易犯的错误，廉价运行、失败响亮。
风险

Lethal Trifecta

Simon Willison：三因子风险——私数据 + 不可信内容 + 外部通信。三个全占 = 致命。
风险

Cognitive Debt

Hunt 2026 提出的术语：AI 交互的累积成本——上下文丢失、agent 行为不可靠——超越技术债。
