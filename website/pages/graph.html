一、边界关系（重要）

Vibe Coding 与 Agentic Programming 是常被混淆的两个范式。Fowler 强调：前者"忘了代码存在"，后者"审查代码"。

二、因果链

频繁 Vibe Coding → Technical Debt 累积 → Vibe Slop → Vibe Coding Hangover。Guardrails 是阻断链。

三、关键决定点

"是否审查代码"是 Vibe vs Agentic 的决定点。"是否每次审批"是 YOLO vs Responsible 的决定点。

关键因果链

⚠ Vibe Coding → Development Hell

频繁 Vibe Coding → 缺乏 Refactor + Spec → Technical Debt 累积 → Code Churn ↑ / Dup ↑ → Vibe Hangover

反向阻断：用 Guardrails + SDD + Mechanical Verification Pipeline 切断链路。

✓ Context Engineering → Hallucination ↓

Context Engineering → 只注入相关 / 校验过的内容 → LLM 注意力集中 → Hallucination 显著减少

⚙ SDD → Agent Loop 效率 ↑

Spec.md 清晰 → Plan 阶段输出高质量任务清单 → Verify 阶段验收标准明确 → Build 阶段少返工
